STORYBENCH — INLINE THINKING LOOPS

Open index.html directly in a browser. No server or network access required.

The two selected concepts are shown in light chat mockups, with a presentation /
video toggle. Both loop continuously. The chat history stays in place; there is
no finished-message reveal or playback UI.

Display: 170 x 156 CSS pixels, based on the marked area in the supplied reference.
Native artwork: 768 x 704 pixels, redrawn with finer detail. Width is twice the
original 384-pixel studies; this is not a scaled-up copy of the old artwork.
Transparent backgrounds allow both illustrations to sit directly in the chat.
Desk content is limited to the lamp, mat, light, and moving creative pieces.

Each 10-second cycle gathers, arranges, produces, then recycles the same pieces
back into the opening motion. Every motion is periodic. Reduced-motion settings
show a still composition. Drawing stops while the browser tab is hidden.

Verification: syntax and whitespace checks; 76 sampled deterministic renders;
identical t=0 and t=1 artwork and near-seam pixel comparison for both modes;
DOM checks of mode switching, multiple loops, reduced motion, and hidden tabs.
Native-resolution and actual-display-size raster contact sheets inspected.
Live browser playback remains unverified: managed extension not connected.
